## Selected Projects

### Reliability-Aware Multimodal Transformer for Sleep Stage Classification
Exploring multimodal physiological-signal learning for sleep-stage classification using EEG, EOG, and EMG data. The project focuses on combining modality-specific representations and accounting for signal reliability.

**Tools and concepts:** Python, deep learning, transformers, physiological signals, Sleep-EDF.

### Self-Supervised Learning on Chest X-rays — SimCLR
Implemented a SimCLR-style contrastive-learning workflow using the NIH ChestXray14 dataset to investigate feature learning from medical images with limited reliance on labelled data.

**Tools and concepts:** Python, PyTorch, self-supervised learning, medical imaging, representation learning.

### SVM-Based EEG Valence Classification
Built a baseline EEG classification workflow using band-power features from multi-channel EEG recordings and an SVM classifier.

**Tools and concepts:** Python, EEG, feature extraction, signal processing, scikit-learn.

### JDL-STAP Radar Signal Processing on FPGA
Working on an FPGA-oriented radar signal-processing project involving target-detection concepts and hardware integration on a Zybo Z7-10 platform.

**Tools and concepts:** Verilog HDL, FPGA, DSP, Vivado, Zybo Z7-10.

### Audio Signal Processing and Track Merging
Developed a Python-based workflow for processing and merging audio tracks, applying practical digital signal-processing concepts.

**Tools and concepts:** Python, audio DSP, FFT, Raspberry Pi.
