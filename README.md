## 💼 Research & Projects

<details>
<summary>🧠 <strong>EEG Sleep Stage Classification — Multisubepoch Feature Learning</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Deep Learning](https://img.shields.io/badge/Deep%20Learning-EE4C2C?style=flat-square&logo=pytorch&logoColor=white) ![Signal Processing](https://img.shields.io/badge/EEG-Signal%20Processing-38BDAE?style=flat-square)

- Developed an **interpretable multisubepoch EEG feature learning pipeline** to capture temporal dependencies across multiple EEG subepochs for robust sleep stage classification
- Applied **glassbox-based classification models** ensuring transparent, explainable, and clinically interpretable decision-making in biomedical signal analysis
- Emphasised model reliability and interpretability to support meaningful analysis of **EEG patterns** in sleep-related biomedical applications

</details>

<details>
<summary>✋ <strong>Hilbert Transform–Based sEMG Hand Gesture Recognition</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Deep Learning](https://img.shields.io/badge/Deep%20Learning-EE4C2C?style=flat-square&logo=pytorch&logoColor=white) ![Signal Processing](https://img.shields.io/badge/sEMG-Hilbert%20Transform-BF91F3?style=flat-square)

- Applied **Hilbert transform-based scanning** to surface EMG signals to extract instantaneous amplitude and phase information for enhanced signal representation
- Engineered discriminative **time–frequency features** from Hilbert-processed sEMG signals to improve separability of hand gesture patterns
- Developed deep learning models capable of learning **robust, generalised representations** from transformed sEMG features for accurate hand gesture recognition

</details>

<details>
<summary>🖼️ <strong>CNN-Based Spatial–Temporal Feature Learning from Grayscale sEMG Images</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![CNN](https://img.shields.io/badge/CNN-Architecture-70A5FD?style=flat-square) ![Computer Vision](https://img.shields.io/badge/Computer-Vision-38BDAE?style=flat-square)

- Developed a **signal-to-image transformation pipeline** converting multichannel sEMG signals into discriminative grayscale representations suitable for deep learning
- Designed and trained a pure **CNN-based architecture** to learn spatial–temporal patterns from encoded sEMG images for biomedical hand gesture recognition
- Demonstrated end-to-end deep learning on biomedical sensor data without handcrafted frequency features

</details>

<details>
<summary>🫁 <strong>Self-Supervised Learning on NIH ChestXray14 — SimCLR Framework</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![SimCLR](https://img.shields.io/badge/SimCLR-Self%20Supervised-BF91F3?style=flat-square) ![Medical AI](https://img.shields.io/badge/Medical-AI-70A5FD?style=flat-square)

- Developed a **SimCLR-based self-supervised learning framework** for thoracic disease detection using the NIH ChestXray14 dataset — no labelled supervision required
- Implemented **contrastive learning strategies** to extract rich and transferable image representations from chest radiographs
- Evaluated performance using **AUC metrics and t-SNE visualisations**, achieving improved generalisation across thoracic disease categories

</details>

<details>
<summary>🎛️ <strong>Multi-Domain Noise Analysis & Denoising on Raspberry Pi</strong></summary>

> ![Raspberry Pi](https://img.shields.io/badge/Raspberry%20Pi-A22846?style=flat-square&logo=raspberry-pi&logoColor=white) ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![Signal Processing](https://img.shields.io/badge/FFT-Signal%20Processing-38BDAE?style=flat-square)

- Designed a **Raspberry Pi–based signal processing system** for comprehensive noise analysis and suppression in both image and audio signals
- Characterised Gaussian, salt-and-pepper, and impulse noise across **time-domain and frequency-domain** representations
- Performed **FFT and 2D FFT** analysis and applied targeted denoising techniques while preserving essential signal details

</details>

<details>
<summary>🧬 <strong>SVM-Based EEG Valence Classifier — 85%+ Accuracy</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![SVM](https://img.shields.io/badge/SVM-Scikit--learn-F7931E?style=flat-square&logo=scikit-learn&logoColor=white) ![EEG](https://img.shields.io/badge/32--Channel-EEG-BF91F3?style=flat-square)

- Extracted **Alpha, Beta, and Theta bandpower features** from 32-channel EEG signals to represent emotional brain activity
- Trained and optimised an SVM classifier achieving **>85% accuracy** in emotional valence classification
- Enabled potential real-time applications in **emotion-aware environments, mental wellness monitoring, and brain-driven IoT systems**

</details>

<details>
<summary>👶 <strong>Infant Cry Signal Classification using ML & MFCC Features</strong></summary>

> ![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![MFCC](https://img.shields.io/badge/MFCC-Feature%20Extraction-70A5FD?style=flat-square) ![ML](https://img.shields.io/badge/Supervised-ML-38BDAE?style=flat-square)
