## 🔬 Research & Projects

<details open>
<summary><strong>🌙 Reliability-Aware Multimodal Transformer for Sleep Stage Classification</strong></summary>

Exploring multimodal physiological-signal learning for sleep-stage classification using EEG, EOG, and EMG signals from the Sleep-EDF Expanded dataset. The proposed direction combines modality-specific feature extraction with reliability-aware fusion and transformer-based learning.

**Focus:** Biomedical AI · Multimodal learning · Sleep staging · Physiological signals  
**Tools:** Python · Deep Learning · Transformers · Signal Processing

</details>

<details>
<summary><strong>🫁 Self-Supervised Learning on Chest X-rays — SimCLR</strong></summary>

Built a SimCLR-style self-supervised learning workflow using the NIH ChestXray14 dataset to explore contrastive representation learning for chest radiographs.

**Focus:** Self-supervised learning · Medical imaging · Contrastive learning  
**Tools:** Python · PyTorch · NumPy · Data visualisation

</details>

<details>
<summary><strong>🧠 SVM-Based EEG Valence Classification</strong></summary>

Developed a baseline EEG classification pipeline using band-power features from multi-channel EEG recordings and a support vector machine.

**Focus:** EEG feature extraction · Theta/Alpha/Beta bandpower · Classification  
**Tools:** Python · Signal Processing · scikit-learn

</details>

<details>
<summary><strong>📡 JDL-STAP Radar Signal Processing on FPGA</strong></summary>

Working on an FPGA-oriented radar signal-processing project, exploring a hardware pipeline for target-detection tasks on the Zybo Z7-10 platform.

**Focus:** Radar DSP · FPGA implementation · Hardware/software integration  
**Tools:** Verilog HDL · Vivado · Zybo Z7-10

</details>

<details>
<summary><strong>🎵 Audio Signal Processing & Track Merging</strong></summary>

Created a Python-based audio-processing workflow to merge vocal and background music tracks, applying practical DSP concepts to audio signals.

**Focus:** Audio DSP · Signal manipulation · Time/frequency analysis  
**Tools:** Python · NumPy · FFT

</details>

<details>
<summary><strong>🔊 Ambient Noise-Based Audio Volume Controller</strong></summary>

Explored an audio-analysis workflow using RMS loudness, framing, smoothing, and frequency-domain features to map ambient sound levels to system-volume adjustments.

**Focus:** Audio feature extraction · RMS energy · FFT · Smoothing  
**Tools:** Python · NumPy · Matplotlib

</details>

<details>
<summary><strong>👶 Infant Cry Signal Classification</strong></summary>

Explored acoustic feature extraction and machine-learning methods for classifying infant-cry audio patterns.

**Focus:** MFCCs · Audio classification · Feature engineering  
**Tools:** Python · Digital Signal Processing · Machine Learning

</details>
